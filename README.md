Безопасные релизы

Чтобы создать ветку - нам нужна ветка от которой мы будем ответвляться
По умолчанию первые ответвления идут от мастер ветки

Для локального ветвления git branch __имя ветки__
git branch __...__ - создаст ветку, но вы остаетесь на текущей ветке 

git branch -r -- remote - покажет удаленные ветки
git branch -a -- all - покажет все ветки

git checkout master - перейти на ветку мастер
git checkout -b __название ветки__ - создать ветку и переместиться на нее

git branch -d __название ветки__ - удалить локальную ветку
                                   удалять ветку можно если вы на ней не находитесь

git push -u origin __название ветки__ - создать ветку в облаке
                                        желательно чтобы названия совпадали

git push origin --delete dev_local_backend_second


мы полезли в изменения веток (пока безконфликтных)
